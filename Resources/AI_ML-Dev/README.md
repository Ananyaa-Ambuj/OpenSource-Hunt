## 🎯 Requirements

Before starting the mentorship, participants should have:

- Basic programming knowledge
- Basic Python knowledge
- Familiarity with Git and GitHub
- Basic mathematics and statistics
- A willingness to experiment and learn

---

## 📤 Submission

For each assignment:

- Complete the task mentioned for the week.
- Push your work to GitHub.
- Include a `README.md` explaining your work.
- Include screenshots/results where appropriate.
- Clearly mention the approach you used.
- Submit your repository/link through the designated submission channel.

> **Submission Policy:** Work submitted must be your own work. You may use
> documentation and learning resources, but understand the code and concepts
> you submit.

# 📚 Weekly Assignments

## Week 1 – Python & Data Science Fundamentals

### 🎯 Objective

Build a strong foundation in Python and the tools commonly used in
Data Science and Machine Learning.

### Tasks

- Revise Python fundamentals.
- Work with NumPy arrays.
- Perform data manipulation using Pandas.
- Create basic visualizations using Matplotlib.
- Explore a real-world dataset.
- Perform basic data cleaning.
- Calculate basic statistical measures.

### 🏆 Assignment

Choose a dataset and perform:

1. Data loading
2. Data cleaning
3. Exploratory Data Analysis
4. Visualization
5. Basic observations

---

## Week 2 – Machine Learning Fundamentals

### 🎯 Objective

Understand what Machine Learning is and how a typical ML workflow works.

### Topics

- Machine Learning fundamentals
- Features and targets
- Training and testing data
- Data preprocessing
- Regression
- Classification
- Model evaluation

### 🏆 Assignment

Build your first Machine Learning model.

Your project should include:

- Dataset
- Data preprocessing
- Train/test split
- Model training
- Predictions
- Evaluation

---

## Week 3 – Supervised Learning

### 🎯 Objective

Learn commonly used supervised learning algorithms.

### Topics

- Linear Regression
- Logistic Regression
- Decision Trees
- Random Forest
- K-Nearest Neighbors
- Model evaluation
- Overfitting and underfitting

### 🏆 Assignment

Choose a classification or regression problem.

Train at least **two different models** and compare their performance.

Your README should explain:

- Why you selected the models
- Evaluation metrics
- Which model performed better
- Your observations

---

## Week 4 – Unsupervised Learning

### 🎯 Objective

Understand how Machine Learning can discover patterns without labelled data.

### Topics

- Clustering
- K-Means
- Dimensionality Reduction
- PCA
- Feature scaling
- Visualization

### 🏆 Assignment

Perform clustering on a dataset.

Visualize the clusters and explain what patterns you discovered.

---

## Week 5 – Deep Learning

### 🎯 Objective

Get introduced to Neural Networks and Deep Learning.

### Topics

- Neural Networks
- Neurons
- Activation Functions
- Loss Functions
- Optimizers
- Forward Propagation
- Backpropagation
- Training and validation

### 🏆 Assignment

Build a simple Neural Network for a classification problem.

You should include:

- Dataset preprocessing
- Model architecture
- Training
- Validation
- Evaluation
- Results

---

## Week 6 – Computer Vision / NLP

Choose **one** track.

### 👁️ Track A – Computer Vision

Explore:

- Image preprocessing
- Image classification
- CNNs
- Image datasets
- Model evaluation

### 💬 Track B – Natural Language Processing

Explore:

- Text preprocessing
- Tokenization
- Text classification
- Embeddings
- Sentiment analysis

### 🏆 Assignment

Build a small AI application using either:

- Computer Vision

**OR**

- Natural Language Processing

---

## Week 7 – Model Deployment

### 🎯 Objective

Learn how to make your Machine Learning model accessible to users.

### Topics

- Saving models
- APIs
- FastAPI / Flask
- Streamlit
- Model serving
- Basic deployment

### 🏆 Assignment

Deploy one of your previous ML models.

Your project should provide a simple interface through which a user
can provide input and receive a prediction.

# 🚀 Final Assignment – Build Your Own AI/ML Project

## 🎯 Objective

Build a complete AI/ML project that demonstrates everything you learned
during the mentorship.

Your project should contain:

- [ ] Problem statement
- [ ] Dataset
- [ ] Data preprocessing
- [ ] Exploratory Data Analysis
- [ ] Model development
- [ ] Model evaluation
- [ ] Results
- [ ] Documentation
- [ ] User interface or API
- [ ] Deployment

### 💡 Project Ideas

You can build something such as:

- Image Classification System
- Sentiment Analysis
- Recommendation System
- Spam Detection
- House Price Prediction
- Disease Prediction
- Object Detection
- Chatbot
- Handwritten Digit Recognition
- News Classification

You are encouraged to come up with your **own idea**.
