# 🤝 Contributing to OpenSource-Hunt

Welcome to OpenSource-Hunt! 🎉

This project is created to help you experience your first Open Source contribution.

You don't need to be an Open Source expert.

Pick an issue, solve it, and create your first Pull Request!

---

## 🚀 Contribution Workflow

Follow these steps:

### 1. Find an Issue

Go to the Issues section and find an issue you would like to work on.

Look for labels such as:

- `good first issue`
- `beginner friendly`
- `easy`
- `documentation`
- `bug`

---

### 2. Ask to Work on the Issue

Comment:

/assign

A maintainer will assign the issue to you.

Please don't start working on an issue that is already assigned to someone else.

---

### 3. Fork the Repository

Click the **Fork** button on GitHub.

This creates your own copy of the repository.

---

### 4. Clone Your Fork

Clone your fork to your computer:

```bash
git clone YOUR_FORK_URL
